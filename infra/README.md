# OmniCompile Core Infrastructure

Docker and Kubernetes orchestration manifests for local development, testing, and cloud deployment.

## Structure

- **`docker/`:** Compose definitions, language worker Dockerfiles, and execution brokers.
- **`kubernetes/`:** Base manifests, Kustomize overlays for native execution, prewarming, and Desktop orchestration.
