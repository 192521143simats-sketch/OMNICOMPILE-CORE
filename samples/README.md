# OmniCompile Core Sample Workloads

Sample source files for C, Python, and Java compilation and optimization.

The [case-study suite](case-studies/README.md) adds 19 deterministic industry-inspired
programs with dependency descriptions, expected outputs, intentional failures,
and an isolated validation command. Its manifest distinguishes compiler errors
from runtime errors and successful programs.

## Contents
- **`c/`:** Sample C source programs (e.g., matrix multiplication, arithmetic evaluation)
- **`python/`:** Sample Python source programs
- **`java/`:** Sample Java programs
